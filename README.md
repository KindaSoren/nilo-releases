# Nilo releases

Desktop installers for **Nilo**, on-device voice typing for Windows, macOS and
Linux. Speech is transcribed on your computer with Whisper; audio never leaves
it.

Download the latest version from the [Releases page](../../releases/latest).

| Platform | File |
|---|---|
| Windows (x64, ARM) | `Nilo-<version>-x64.exe`, `Nilo-<version>-arm64.exe` |
| macOS (Apple Silicon, Intel) | `Nilo-<version>-arm64.dmg`, `Nilo-<version>-x64.dmg` |
| Linux (x64, ARM) | `.AppImage` or `.deb` |

Installed copies of Nilo check this repository for updates. The `latest*.yml`
files and `.blockmap` files attached to each release are the update metadata;
you do not need to download them.

Nilo for Android is on Google Play. Source code is not published here; this
repository only hosts release files.
